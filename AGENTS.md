# AGENTS.md

Canonical context for any AI or human contributor lives in **[`CLAUDE.md`](CLAUDE.md)** at
the repo root. Read it first — it is model-agnostic (Claude, Codex, anything else).

The owner works between Claude Code and Codex interchangeably. There is **one shared context**
(`CLAUDE.md`). The running record of what each assistant has done is the **Working log** in
[`docs/archive/WORKING_LOG_2026.md`](docs/archive/WORKING_LOG_2026.md). When you finish work,
add a short entry at the top of it so the next assistant picks up cleanly.
