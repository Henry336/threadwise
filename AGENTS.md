# AGENTS.md

Canonical context for any AI or human contributor lives in **[`CLAUDE.md`](CLAUDE.md)** at
the repo root. Read it first — it is model-agnostic (Claude, Codex, anything else).

The owner works between Claude Code and Codex interchangeably. There is **one shared context**
(`CLAUDE.md`), and its **Working log** section is the running record of what each assistant has
done. When you finish work, add a Working-log entry there so the next assistant picks up cleanly.
